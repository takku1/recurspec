# Case-study pair logs

One markdown file per R-400–R-403 matched pair. Create with
`recurspec study init` and assign with `recurspec study assign` **before** either
arm starts. Record a first accepted implementation only with
`recurspec study accept` after a verify command exits 0 and maker ≠ checker.
Outcome cells stay `unknown` until observed.

Recurspec itself is not an eligible subject project.
